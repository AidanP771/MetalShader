# MetalMix user guide

> MetalMix is not ready for players yet. This page is the outline that gets
> filled in as features land (M4b onward). Write it for a Sims player, not a
> programmer.

## Planned sections

1. **What MetalMix does** (with before and after screenshots)
2. **Installing** with the MetalMix Installer, step by step
3. **Turning MetalMix off**
   - Hold Option while the game starts to skip it once.
   - Create a file named `DISABLED` in `~/Library/Application Support/MetalMix/`
     to keep it off.
   - Uninstall to remove it completely.
4. **Beginner mode:** choosing a preset, the Intensity slider, before and after
5. **Making your own look** with the Mix builder
6. **Saving and sharing presets**
7. **Hotkeys**
8. **Your saves:** what MetalMix backs up and how to restore
9. **Troubleshooting:** the game will not start, effects look wrong, slow
   performance on a MacBook Air
10. **After a game update:** re-patching with the installer
